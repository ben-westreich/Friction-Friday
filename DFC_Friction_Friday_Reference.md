# DFC Friction Friday — Script & Description Reference Guide

> This document captures all existing Friction Friday scripts and descriptions, the proven template formula, approved product terminology, and style guidelines for writing future content.

---

## Template Formula

### Script Template

```
Hi everyone. This week on Friction Friday, we have the [YEAR(S)] [MAKE] [MODEL].
[1–2 sentences on the vehicle's character, purpose, or what makes it distinctive.]
DFC's 5000 Series Advanced Brake Pads and GeoSpec Coated Rotors [benefit 1] and [benefit 2].
GeoSpec coated rotors [corrosion benefit] while OE-specific [fitment/designs] ensure [installation/fit benefit].
DFC [proudly] supports the [MODEL] with a complete braking solution.
```

### Description Template

```
The [YEAR(S)] [MAKE] [MODEL] [vehicle character hook], making [precise/reliable/dependable/smooth] braking essential.
The DFC 5000 Brake Kit with GeoSpec Rotors [delivers/provides] OE-level fit[,] [primary benefit], and [secondary benefit].
```

## Approved Product Terminology

| Term | Usage |
|------|-------|
| DFC 5000 Series Advanced Brake Pads | Full name in scripts |
| GeoSpec Coated Rotors | Full name in scripts |
| DFC 5000 Brake Kit with GeoSpec Rotors | Used in descriptions |
| OE specifications / OE-specific fitment / OE-level fit | Interchangeable across contexts |
| Strong initial bite / confident bite | Performance vehicle language |
| Smooth pedal feel / consistent pedal feel / stable pedal feel | Comfort/luxury vehicle language |
| Quiet operation / quiet performance | Secondary benefit |
| Corrosion resistance | GeoSpec rotor benefit |
| Complete braking solution | Closing phrase |

---

## Style Notes

- **Opening**: Always "Hi everyone. This week on Friction Friday, we have the…" — never vary this opener
- **Year format**: Use em-dash range for multi-year (2023–2026), single year for single model year
- **Vehicle character**: Tailor 1–2 sentences to what makes that specific vehicle unique — rally performance, luxury refinement, electric drivetrain, family versatility, etc.
- **Benefit language**: Match the tone to the vehicle — use "bite" and "aggressive" for performance vehicles; use "smooth," "refined," and "quiet" for luxury/family vehicles
- **EV notes**: When the vehicle is electric or hybrid, acknowledge regenerative braking and/or increased weight as the reason reliable braking matters
- **Script length**: ~80–110 words
- **Description length**: 2 sentences, ~40–55 words
- **Closing**: Scripts typically close with "DFC [proudly] supports the [MODEL] with a complete braking solution."

## Vehicle Character Cues — Quick Reference

Use the vehicle's character to choose the right benefit language:

| Vehicle Type | Character Hook Examples | Benefit Language |
|---|---|---|
| Performance / Sports | Rally-inspired, turbocharged, AWD, track-ready | Strong bite, aggressive driving, sharp control |
| Luxury | Italian craftsmanship, refined, responsive | Smooth pedal response, quiet operation, precise |
| Crossover / Compact | Bold styling, agile handling | Confident bite, smooth pedal feel, quiet performance |
| EV / Hybrid | Regenerative systems, increased weight, advanced tech | Stable pedal feel, reliable, quiet operation |
| Family / SUV | Versatility, daily driving, families | Dependable, smooth pedal feel, consistent stopping |
